## 💡 How I build

- **Automate the last mile.** A model nobody opens is a dead model. Every project ends in a scheduled report, email or chat — in front of the person who acts.
- **Humans decide, AI surfaces.** Systems flag deviations with their value and evidence; the planner or engineer owns the decision.
- **Constraints are requirements.** On-prem LLMs, proxies, no external AI on company data — designed for from day one.
- **Config over code.** Thresholds, targets and routing live in configuration (and now in admin UIs) so operations can change them without a developer.
- **Govern before go-live.** Risk classification and a release checklist are a gate, not an afterthought.
